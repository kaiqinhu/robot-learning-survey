VLA: Vision-Language-Action Models

从预训练视觉语言模型到通用机器人策略的演进

核心思路

VLA 的核心 insight：大规模 VLM (如 PaLM-E, LLaMA) 已经在互联网数据上学会了丰富的语义理解和视觉推理能力。通过在 VLM 基础上增加 action 输出头，可以将这些能力迁移到机器人控制中——用语言理解任务意图，用视觉感知环境状态，直接输出低层动作。

VLA 标准架构 ┌──────────────────────────────────────────┐ │ Pre-trained VLM Backbone │ │ ┌──────────┐ ┌───────────┐ │ │ │ Vision │ │ Language │ │ │ │ Encoder │ │ Encoder │ │ │ │(ViT/SigLIP)│ │(LLaMA/ │ │ │ │ │ │ PaLM) │ │ │ └─────┬────┘ └─────┬─────┘ │ │ └──────┬───────┘ │ │ ▼ │ │ ┌──────────────────┐ │ │ │ Fused Features │ │ │ └────────┬─────────┘ │ │ ▼ │ │ ┌────────────────────────┐ │ │ │ Action Head │ │ │ │ (MLP / Tokenizer / │ │ │ │ Flow Matching) │ │ │ └───────────┬────────────┘ │ └──────────────┼───────────────────────────┘ ▼ Robot Joint Actions [a₁, a₂, ..., aₙ]

21 个机构、22 种机器人、527 种技能、160K+ 任务。证明跨具身正迁移：在一个机器人上的数据可以提升另一个机器人的性能。

OpenVLA

VLM + Flow Matching 架构。连续动作生成替代离散 token，适合高精度操作。叠衣服、清桌子等高灵巧任务表现优异。

FAN-VLA: Feasible Action Neighborhood Regularization

SJTU / Huawei | Niu et al. | arXiv:2604.01570

发现机器人状态空间中存在"可行动作邻域"(FAN)——微小动作差异不影响结果。用高斯先验正则化 VLA 输出分布，对齐物理操作的内在容错性。

核心思想: 状态 s 附近存在可行动作邻域 FAN(s) ┌───────────────────────────┐ │ Action Space │ │ ┌─────────┐ │ │ │ FAN(s) │ │ ← 邻域内动作等效 │ │ ·a_gt │ │ │ │ ·a' │ │ 高斯先验 N(a_gt, σ²) │ │ ·a'' │ │ 约束输出在 FAN 内 │ └─────────┘ │ └───────────────────────────┘ 效果: SFT 和 RFT 样本效率 ↑, OOD 泛化 ↑
核心 Insight: 机器人动作空间有内在容错性，VLA 不应追求点估计精确匹配 GT，而应输出覆盖整个可行邻域的分布。

Tex3D: 3D Adversarial Textures Attack VLA

ECNU / Tsinghua | Chen et al. | arXiv:2604.01618

首次对 VLA 进行端到端 3D 对抗纹理攻击。通过前景-背景解耦(FBD)实现可微纹理优化，轨迹感知优化(TAAO)确保跨视角攻击有效性。

攻击流程: ┌──────────┐ FBD ┌───────────────┐ │ 3D物体 │ ──────────►│ 对抗纹理优化 │ │ (操作目标)│ 可微渲染 │ ∂L_vla/∂texture│ └──────────┘ └───────┬───────┘ │ TAAO ┌──────▼──────┐ │ 关键帧优先级 │ │ 顶点参数化 │ └──────┬──────┘ ▼ VLA 任务失败率: 96.7% ← 物体表面贴对抗纹理即可
核心 Insight: VLA 对 3D 物理域攻击极度脆弱。标准仿真器无法提供从 VLA loss 到物体外观的可微路径——FBD 通过双渲染器对齐解决此问题。

FocusVLA: Visual Attention for Action

HIT-SZ / DaiMon | Zhang et al. | arXiv:2603.28740

诊断 VLA 三大视觉瓶颈并逐一解决：架构偏见忽略视觉细节、过多 visual token 分散注意力、无关视觉信息引入噪声。

VLA 视觉三大瓶颈与解法: 问题1: 架构偏见 → language shortcut 跳过视觉 解法: Modality Cascaded Attention (消除捷径) 问题2: visual token 过多 → 注意力稀释 解法: Focus Attention 动态选择 task-relevant patches ┌─────────────────────────┐ │ 全部 visual patches │ │ [x][x][✓][x][✓][x] │ ← 动态选择 │ ↓ ↓ │ │ task-relevant only │ → 送入 action head └─────────────────────────┘ 问题3: 无关视觉信息 → 噪声 解法: 显式调制 relevant patch 影响力
核心 Insight: VLA 性能瓶颈不在视觉表征质量，而在视觉信息如何被利用。实验证明：更好地用现有视觉表征 > 提升视觉编码器。

Progress-Aware VLA

PKU | Yan et al. | arXiv:2603.27670

大多数 VLA 缺乏任务进度感知，依赖手工启发式判断任务终止。引入可微进度引导管线：预训练进度估计器 + 逆动力学世界模型。

可微进度引导管线: ┌──────────┐ ┌──────────────────┐ ┌──────────────┐ │ Action │────►│ Inverse Dynamics │────►│ Future Latent│ │ Tokens │ │ World Model │ │ Visual State │ └──────────┘ └──────────────────┘ └──────┬───────┘ │ ┌───────▼───────┐ │ Progress │ │ Estimator │ │ p(t) ∈ [0,1] │ └───────┬───────┘ │ max progress │ regularization ▼ refine action tokens
核心 Insight: 进度估计器在大规模无监督视频-文本机器人数据上预训练，预测残差仅 0.07（0-1 scale），且零样本迁移到未见真机场景。

XVR: Cross-View Spatial Relations

KAIST | Jeong et al. | arXiv:2603.27967

VLM 缺乏多视角空间推理能力。构建 100K 视觉问答数据集（18K 3D 场景 + 70K 机器人轨迹），训练三类跨视角能力。

三类跨视角空间推理任务: ┌─────────────────────────────────────────────────┐ │ 1. Correspondence — 跨视角物体匹配 │ │ View A: [杯子在左] ←→ View B: [杯子在右] │ │ │ │ 2. Localization — 目标位置识别 │ │ "从 View C 看，机械臂末端在哪?" → (x,y) │ └─────────────────────────────────────────────────┘ 数据: 18K 3D scenes + 70K robot trajectories = 100K QA 效果: VLA backbone 换用 XVR → RoboCasa 成功率 ↑
核心 Insight: 显式训练跨视角空间关系比增大模型或数据更有效。3D 理解能力可以通过 QA 形式注入 VLM，无需修改架构。

VLA + RL 微调 (2026 最热方向)

2025.05 里程碑

VLA-RL: Scalable RL for VLA

Tsinghua / NTU | Lu et al. | arXiv:2505.18719

将 LLM RLHF 范式完整迁移到 VLA：VLA 在真实环境中交互，用任务成功信号做 RL 微调。证明 RL 阶段可以在不破坏预训练泛化的前提下显著提升任务成功率和鲁棒性。

VLA-RL 三阶段 (= LLM Pre-train → SFT → RLHF): ┌────────────────────────────────────────────┐ │ Phase 1: VLM Pre-train (Internet-scale) │ │ Vision + Language → 语义理解 │ │ ▼ │ │ Phase 2: IL/SFT (Robot demonstrations) │ │ Obs + Lang → Action (模仿学习对齐) │ │ ▼ │ │ Phase 3: RL Fine-tune (Env interaction) │ │ Task success reward → 超越演示水平 │ │ 策略梯度优化, 不破坏预训练泛化 │ └────────────────────────────────────────────┘ 效果: 成功率显著↑, 泛化保持
核心 Insight: VLA 的 IL/SFT 阶段受限于演示数据的质量和覆盖范围。RL 微调通过环境交互突破此上界——类似 LLM 中 RLHF 突破 SFT 的天花板。
arXiv 2505.18719 →
2026.03

VLA-OPD: On-Policy Distillation

HKUST(GZ) | Zhong et al. | arXiv:2603.26666

大 VLA teacher 给小 student rollout 重标签，实现 on-policy distillation。解决直接 RL 微调大型 VLA 的计算瓶颈：teacher 只在标注时运行，student 轻量在线学习。

On-Policy Distillation: ┌────────────────────────────────────────────┐ │ Large VLA Teacher (offline, 标注用) │ │ ↓ relabel student rollouts │ │ Small Student Policy (online, 部署用) │ │ ↓ on-policy RL with teacher labels │ │ 效果: 桥接 offline SFT ←→ online RL │ │ 无需大模型在线推理, 降低计算成本 10x+ │ └────────────────────────────────────────────┘
核心 Insight: 大 VLA 直接做 RL 太贵，小模型直接 RL 又太弱。OPD 用大模型标注小模型的在线经验，兼顾大模型的知识和小模型的效率。
arXiv 2603.26666 →
2025.06

TGRPO: Trajectory-wise GRPO for VLA

NWPU | Chen et al. | arXiv:2506.08440

修复 GRPO 在轨迹级任务中的 token 不均衡问题：标准 GRPO 在 token 级归一化 advantage，导致长轨迹中关键决策点的信号被稀释。TGRPO 在轨迹级归一化，保留时序结构中的关键信号。

GRPO vs TGRPO: ┌────────────────────────────────────────────┐ │ GRPO: token-level normalize │ │ [t1][t2][t3]...[tN] → 每个 token 独立 │ │ 问题: 关键决策 token 信号被大量填充稀释 │ │ │ │ TGRPO: trajectory-level normalize │ │ [───── trajectory ─────] → 整体归一化 │ │ 优势: 保留轨迹内关键决策点的相对重要性 │ │ 方差更低, 收敛更稳定 │ └────────────────────────────────────────────┘
核心 Insight: GRPO 的 token 级归一化对 LLM 文本生成合理，但对机器人轨迹不合理——轨迹中 95% 的 token 是常规运动，5% 是关键决策。轨迹级归一化保护了这 5% 的信号。
arXiv 2506.08440 →
2025.02

ConRFT: Consistency Policy for VLA RL

CASIA / UCAS | Chen et al. | arXiv:2502.05450

用 Consistency Model 替代 Diffusion 作为 VLA 的动作头，使 RL 微调更高效：单步生成 + 端到端可微。在操作任务上比 Flow Matching + RL 收敛更快。

ConRFT 架构: ┌────────────────────────────────────────────┐ │ VLM Backbone → Consistency Action Head │ │ (单步生成, 无需迭代去噪) │ │ ▼ │ │ RL Fine-tune: │ │ ·端到端可微 (vs Diffusion 需多步展开) │ │ ·单步采样 → 直接策略梯度 │ │ ·收敛速度: 2-3x faster than Flow+RL │ └────────────────────────────────────────────┘
核心 Insight: Diffusion/Flow 的多步去噪阻碍 RL 梯度传播。Consistency Model 的单步生成天然适配 RL——无需 DMPO 那样的额外蒸馏步骤。

KineVLA: 运动学感知 VLA

Tencent / ZJU | Han et al. | arXiv:2603.17524

将运动学信息注入 VLA：高层预测末端执行器目标位姿，低层通过逆运动学求解关节动作。双层分解使同一 VLA 可跨不同机器人具身迁移。

KineVLA 双层分解: ┌────────────────────────────────────────────┐ │ VLM Backbone (obs + lang) │ │ ▼ │ │ High-level: 末端执行器目标位姿 (SE3) │ │ (具身无关, 可跨机器人迁移) │ │ ▼ │ │ Low-level: IK 求解器 → 关节动作 │ │ (具身相关, 按机器人 URDF 计算) │ └────────────────────────────────────────────┘ 跨具身迁移: 换机器人只需换 IK 求解器
核心 Insight: VLA 直接输出关节角度把"运动学知识"的负担交给了网络。KineVLA 将这个负担交还给解析 IK 求解器，VLA 只需预测具身无关的末端目标。

ST-VLA: 4D 时空 VLA

NJU | Wu et al. | arXiv:2603.13788

引入时间动态编码和空间自适应 tokenization，让 VLA 具备 4D (3D+时间) 时空推理能力。解决标准 VLA 只看单帧静态图的根本缺陷。

ST-VLA 4D 推理: ┌────────────────────────────────────────────┐ │ 时间维: Temporal Dynamic Encoding │ │ [frame_t-2] [frame_t-1] [frame_t] │ │ → 编码运动趋势和速度变化 │ │ │ │ 空间维: Spatial Adaptive Tokenization │ │ → 动态分配 token 预算给运动区域 │ │ 静止背景少 token, 运动前景多 token │ │ │ │ 4D = 3D空间 + 时间 → 理解物体运动轨迹 │ └────────────────────────────────────────────┘
核心 Insight: 标准 VLA 输入单帧图像，本质上是"看照片做决策"。ST-VLA 通过时序编码让模型"看视频做决策"，时空信息提供运动预测的物理直觉。
arXiv 2603.13788 →
2026.03

AR-VLA: 真自回归动作专家

INSAIT / KU Leuven | Hu et al. | arXiv:2603.10126

将动作生成回归到纯自回归范式：像 LLM 生成 token 一样逐维度生成动作。证明精心设计的自回归动作头可以媲美 Diffusion/Flow Matching，同时推理更简单。

AR-VLA vs Diffusion VLA: ┌────────────────────────────────────────────┐ │ Diffusion/Flow VLA: │ │ noise → 多步去噪 → action │ │ 优点: 多模态 缺点: 慢, RL难微调 │ │ │ │ AR-VLA: │ │ a_1 → a_2 → a_3 → ... → a_n │ │ 像 LLM token-by-token 生成 │ │ 优点: 简单, 快, 天然适配 RL │ │ 关键: 动作维度排序 + 条件依赖建模 │ └────────────────────────────────────────────┘
核心 Insight: Diffusion 不是动作生成的唯一选择。精心设计的自回归动作头（维度排序+条件依赖）可以达到同等多模态建模能力，且天然兼容 LLM 的自回归训练基础设施。

FAST: 高效动作 Tokenization

MIT | Pertsch et al.

提出高效的机器人动作 tokenization 方案。通过学习压缩的动作 token 表示，使 VLA 的自回归动作生成效率大幅提升，同时保持精度。解决了 VLA 中"动作 token 数量多→推理慢"的核心瓶颈。

动作序列存在大量冗余——FAST 用学习的 tokenizer 压缩冗余，类似 BPE 对文本的作用。
2025 4x cited

UniVLA: 任务中心潜在动作统一

PKU | Li et al.

将不同类型的机器人动作统一到潜在动作空间中。通过任务中心的动作抽象，使单一 VLA 模型可跨不同动作空间的机器人迁移，无需为每种机器人分别训练。

机器人动作空间高度异构（关节角 vs 末端位姿 vs 夹爪）——UniVLA 用潜在空间统一消除此障碍。

TraceVLA: 视觉轨迹提示

SJTU | Zheng et al.

在 VLA 输入中叠加视觉轨迹提示（历史末端轨迹在图像上的投影）。无需修改架构，仅通过输入增强即可显著提升 VLA 的时空感知能力。简单有效，被多篇后续工作采用。

最简单的时序信息注入方式——在图像上画出运动轨迹，让 VLA "看到" 历史运动趋势。

WorldVLA: 自回归动作世界模型

HKU | Li et al.

在 VLA 的自回归框架内同时预测动作和未来视觉状态。统一动作生成和世界预测，是 VLA 和 WAM 融合的早期探索，直接启发了 AtomVLA 等后续混合工作。

WorldVLA 证明自回归 VLA 可以"免费"获得世界建模能力——只需在 token 序列中加入未来视觉 token。
