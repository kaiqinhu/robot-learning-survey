Diffusion Policy: 扩散模型驱动的机器人策略

从 DDPM 到 Flow Matching — 模仿学习的新 SOTA

核心原理

Diffusion Policy 将策略建模为条件扩散/流匹配生成模型：给定当前观测，从高斯噪声逐步去噪生成一段未来动作序列。

Diffusion Policy 核心: 训练: 学习去噪过程 ┌────────┐ 加噪 ┌──────────┐ 学习逆过程 ┌────────────┐ │ GT动作 │ ──────► │ 噪声动作 │ ◄──────────── │ 去噪网络 │ │ 序列 │ │ + 观测条件│ │ ε_θ(aₜ,t,o)│ └────────┘ └──────────┘ └────────────┘ 推理: 迭代去噪生成 ┌──────┐ K步去噪 ┌──────────┐ │ 纯噪声│ ──────────►│ 动作序列 │ (action chunking) │ + obs │ │ [a₁...aH]│ └──────┘ └──────────┘ 关键优势: ✓ 多模态动作分布建模 (同一状态多种可行动作) ✓ Action Chunking 减少复合误差 ✓ 训练稳定 (去噪目标简单) ✓ 数据高效 (10-50 个 demo 即可)

里程碑演进

2023.06

Diffusion Policy (Chi et al.)

开创性工作：DDPM 建模多模态动作分布 + Action Chunking。~100 步去噪→DDIM 10 步。证明扩散模型可直接用于机器人策略。

2023.06

ACT / ALOHA (Zhao et al.)

CVAE + Action Chunking Transformer。非扩散路线但同期发表，推动了 action chunking 成为标配。双臂遥操作系统影响深远。

2024.04

3D Diffusion Policy / DP3

3D 点云替代 2D 图像输入，10 条 demo 解决复杂 6-DOF 操作。证明 3D 表征对数据效率的关键作用。

2024.09

Consistency Policy

将 Consistency Model 引入机器人策略：1-2 步生成，推理加速 10x。首次证明无需多步去噪也能保持多模态。

2024.10

π₀ — Flow Matching VLA

VLM backbone + Flow Matching 动作头。连续流匹配替代离散 token，适合高精度灵巧操作。开启 VLA + Flow 融合路线。

2026.01

DMPO — 真正单步 >120Hz

MeanFlow 数学推导单步推理 + 分散正则化 + RL 微调。首次实现实时扩散策略推理，打通 Diffusion→RL 全链路。

2026.04

MV-VDP / POCO — 新 SOTA

多视角视频扩散策略（10 demo 超越 VLA）+ 模型无关 RL 微调框架（真机 96.7%）。Diffusion Policy 进入成熟期。

多模态与视频扩散

2026.04

MV-VDP: Multi-View Video Diffusion Policy

CASIA / Tsinghua | Li et al. | arXiv:2604.03181

同时预测多视角热力图视频和 RGB 视频。不仅指定机器人做什么动作，还预测环境如何响应这些动作。仅 10 条轨迹，无需额外预训练，即可完成复杂真实世界任务。超越 VLA 和 3D-based 方法。

Multi-View Obs ──┐ (RGB × N views) ├──► Video Diffusion ──► 预测视频 (RGB + Heatmap) Heatmap × N ─────┘ Backbone │ ▼ Action Head ──► 动作序列
核心 Insight: 通过多视角视频扩散同时建模动作与环境响应，使策略具备"想象未来"的能力，仅需 10 条演示即可超越需要大量预训练的 VLA 方法。

RL 微调扩散策略

2026.04 RL+Diffusion

POCO: RL Fine-tune Diffusion Policy

CASIA / UCAS | Chen et al. | arXiv:2604.01860

解决"如何用 RL 微调扩散策略"的关键难题。将策略改进建模为后验推断，通过 EM 算法将 reward 加权隐式后验蒸馏到策略中。模型无关设计可扩展到大型 VLA。真机 4 个接触密集任务 96.7% 成功率。

Diffusion Policy (预训练) │ ▼ ┌─ E-step: 采样 → reward 加权 → 隐式后验 q*(a|o) ─┐ │ │ └─ M-step: 蒸馏 q* 到 π_θ (策略更新) ◄──────────────┘ │ ▼ (迭代收敛) RL-refined Policy → 96.7% 真机成功率
核心 Insight: 将 RL 微调扩散策略转化为 EM 后验推断问题，避免直接对扩散过程做策略梯度，实现了模型无关的稳定 RL 微调范式。
arXiv 2604.01860 →
2026.01

DMPO: One-Step Generation >120Hz

SYSU | Zou et al. | arXiv:2601.20701

真正的单步生成，无需知识蒸馏。三要素：MeanFlow (数学推导单步推理) + 分散正则化 (防止表征坍塌) + RL 微调 (超越专家演示)。操作和运动任务均超越多步 baseline，GPU 上达数百 Hz。

噪声 z ──► MeanFlow (单步!) ──► 动作序列 │ 三大支柱: ├─ MeanFlow: v_θ 直接映射噪声→动作 (无需迭代) ├─ 分散正则化: 防止所有噪声坍塌到同一输出 └─ RL fine-tune: 突破演示上界 推理速度: >120 Hz
核心 Insight: 通过 MeanFlow 理论证明扩散模型可精确单步生成，配合分散正则化解决模式坍塌，首次实现 >120Hz 实时扩散策略推理。
arXiv 2601.20701 →
2024.10

OneDP: One-Step Diffusion Policy

NVIDIA / UT Austin | Wang et al. | arXiv:2410.21257

通过自蒸馏将多步扩散策略压缩为单步生成器。不需要额外教师模型——策略自己蒸馏自己。在灵巧操作任务上实现 10x 推理加速且性能无损。

OneDP 自蒸馏: ┌────────────────────────────────────────────┐ │ 多步 Diffusion Policy (Teacher = Self) │ │ ▼ 自蒸馏 │ │ 单步 Student Policy │ │ noise → 1-step → action │ │ │ │ 关键: Teacher 和 Student 共享权重 │ │ 渐进式减少步数: 10→5→2→1 │ │ 每轮 Student = 上轮蒸馏结果 │ └────────────────────────────────────────────┘ 推理加速: 10x 性能损失: <2%
核心 Insight: 不需要独立的教师模型——多步扩散策略本身就是最好的教师。渐进式自蒸馏比一步到位的蒸馏更稳定。
arXiv 2410.21257 →

2025.01

REFINE-DP: 人形全身 Diffusion + RL

Georgia Tech | Gu et al. | arXiv:2603.13707

将 Diffusion Policy 从桌面操作扩展到人形全身 loco-manipulation。先用人类演示训练 Diffusion Policy，再用 RL 微调使其适应真实物理约束。首次在人形机器人上验证 Diffusion+RL 路线。

REFINE-DP 两阶段: ┌────────────────────────────────────────────┐ │ Phase 1: Diffusion Policy Pre-train │ │ 人类全身运动演示 → 扩散策略 │ │ (覆盖 locomotion + manipulation) │ │ ▼ │ │ Phase 2: RL Fine-tune │ │ 物理约束 reward (稳定性/能耗/安全) │ │ → 适应真实动力学 │ │ → 超越演示水平 │ └────────────────────────────────────────────┘ 目标平台: 人形机器人全身 loco-manipulation
核心 Insight: Diffusion Policy 在桌面操作大获成功，但人形全身控制需要额外的物理约束。RL 微调弥补了演示数据中缺失的动力学知识（稳定性、能耗等）。

2025.07

FlowRL: Flow + RL 统一分类框架

Georgia Tech | Gao et al. | arXiv:2603.27450

首次对 Flow/Diffusion + RL 的所有集成方式做系统分类：策略梯度法、后验推断法、蒸馏法、引导法。提供模块化开源框架和统一 benchmark，使不同方法可公平对比。

FlowRL 四类集成方式: ┌────────────────────────────────────────────┐ │ 1. Policy Gradient (直接梯度) │ │ DMPO: 单步可微 → 直接策略梯度 │ │ │ │ 2. Posterior Inference (后验推断) │ │ POCO: E-step采样 → M-step蒸馏 │ │ │ │ 3. Distillation (蒸馏法) │ │ reward-weighted 样本 → 蒸馏到策略 │ │ │ │ 4. Guidance (引导法) │ │ reward gradient → 引导去噪方向 │ └────────────────────────────────────────────┘ 开源: 统一框架 + benchmark + 公平对比
核心 Insight: Flow/Diffusion + RL 的集成方式看似繁多，实际归纳为四类范式。策略梯度法最直接但需单步可微，后验推断法最通用但需额外采样。
