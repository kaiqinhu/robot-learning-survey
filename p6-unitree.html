运动控制 (Locomotion)

2026.03

G1 Running 3.3 m/s

Caltech | Olkin et al. | arXiv:2603.25902

从单个人类演示生成优化周期参考库。目标条件 + 控制引导 reward。真机 3.3 m/s 跑步 + 全自主感知规划避障。

核心 Insight: 仅需单个人类跑步演示即可生成完整周期参考库，结合目标条件 RL 实现人形机器人创纪录的 3.3 m/s 户外动态跑步。

核心 Insight: 人类行走数据蕴含丰富的导航先验，Diffusion 轨迹预测可零样本迁移至人形机器人，跨越具身鸿沟。

Latent-Driven Text-to-Locomotion

NTU | Yuan et al. | arXiv:2603.17927

自然语言直接驱动全身运动。物理合理性优化 (PP-Opt) 双向耦合生成器和控制器，形成自改进循环。免去传统重定向步骤。

双向耦合自改进循环: ┌──────────────────────────────────────────────┐ │ Text ──► Diffusion Motion Generator │ │ │ 正向: 生成运动 │ │ ▼ │ │ PP-Opt (物理合理性优化) │ │ │ 反向: 优化后的 rollout │ │ │ → 微调生成器 │ │ ▼ │ │ Teacher-Student RL Controller │ │ │ │ │ ▼ 自改进循环 │ │ G1 跟踪 latent-conditioned 运动 │ └──────────────────────────────────────────────┘ 免重定向: 无需 SMPL → robot 的运动映射
核心 Insight: 生成器和控制器双向耦合——控制器的物理 rollout 反过来改进生成器的潜在空间分布，形成自改进闭环，彻底绕过传统 retarget 步骤。

ECHO: Edge-Cloud Humanoid Control

HKUST(GZ) / LimX | Jia et al. | arXiv:2603.16188

云端扩散模型生成运动参考 (~1s)，边端 RL tracker 闭环执行 (1kHz)。38 维紧凑运动表征 + 自动跌倒恢复。G1 零硬件微调执行多样文本指令。

边-云协同架构: ┌──── Cloud GPU ────────────────────┐ │ Text ──► 1D UNet + CLIP │ │ (DDIM 10步 ~1s) │ │ │ │ │ 38-dim 运动表征序列 │ │ [关节角, 根速度, 根高度, 6D朝向] │ └──────────────┬────────────────────┘ │ 下发 ┌──── G1 Edge ─┴────────────────────┐ │ RL Tracker (Teacher-Student) │ │ + 对称性约束 + Domain Rand │ │ + Evidential Adaptation Module │ │ → PD Control @ 1kHz │ │ │ │ 跌倒? → IMU 检测 → 恢复库 │ └───────────────────────────────────┘ FID 0.029 | R-Precision Top-1 0.686
核心 Insight: 将重计算（动作生成）放云端、轻推理（闭环跟踪）放边端，用 38 维紧凑表征桥接——既享受大模型的生成能力，又满足实时控制需求。

Dream2Act: Zero-Shot via Video Generation

HKUST(GZ) | Xu et al. | arXiv:2603.19709

给定机器人和目标物体图像，视频生成模型"想象"机器人完成任务。提取机器人原生关节轨迹后执行。踢球、坐沙发、打沙袋、拥抱箱子 — 37.5% 成功率 (传统重定向 0%)。

Robot-Centric 零样本交互: ┌────────────────┐ ┌────────────────┐ │ 机器人当前图像 │ │ 目标物体图像 │ └───────┬────────┘ └───────┬────────┘ └─────────┬─────────┘ ▼ ┌──────────────────────────────────┐ │ Video Generation Model │ │ "想象"机器人完成任务的视频 │ │ (robot-native 坐标空间) │ └──────────────┬───────────────────┘ ▼ ┌──────────────────────────────────┐ │ High-fidelity Pose Extraction │ │ → 机器人原生关节轨迹 │ └──────────────┬───────────────────┘ ▼ Whole-body Controller → G1 执行 踢球 / 坐沙发 / 打沙袋 / 拥抱: 37.5% (传统 retarget: 0%)
核心 Insight: 在机器人原生坐标空间内"做梦"而非从人类动作重定向——消除形态差距(morphology gap)，使传统方法完全无法完成的全身交互任务首次变为可能。

模仿学习与传感器 (Imitation Learning)

2026.03

G1 Sensor Benchmark for IL

Leibniz Uni. Hannover | Kühn et al. | arXiv:2603.28422

基准测试 14 种传感器组合用于 G1 模仿学习。结论：数据有限时，更多传感器反而降低性能。

14 种传感器组合 × 2 任务: ┌────────────────────────────────────────────────┐ │ 最优配置: 主动立体相机 (最小配置) │ │ 空间泛化任务: 87.5% ✓ │ │ 结构化操作: 94.4% ✓ │ │ │ │ 加入压力传感器后: │ │ 结构化操作: 67.3% ✗ (低信噪比干扰) │ │ │ │ 反直觉结论: │ │ 更多模态 ≠ 更好 (数据有限时) │ │ 视觉 >> 触觉+本体 (低数据域) │ └────────────────────────────────────────────────┘ 开源: Unified Ablation Framework (传感器掩码)
核心 Insight: 反直觉——在数据有限时多模态传感器反而有害。额外模态引入的噪声超过其信息增益，最简主动视觉配置反而最优。
arXiv 2603.28422 →

NMR: Neural Motion Retargeting

NJU / Huawei | Zhao et al. | arXiv:2603.22201

将传统优化重定向问题重新建模为学习数据分布。CEPR 层次数据 pipeline + 非自回归 CNN-Transformer。消除关节跳变和自碰撞，加速下游全身控制策略收敛。

NMR 流水线: 人类动捕 → VAE Motion Clustering → K 个运动簇 │ ┌─────────────────────────┘ ▼ ┌──────────────────────────────────┐ │ Per-Cluster RL Expert │ │ (并行仿真中修复物理不合理动作) │ └──────────────┬───────────────────┘ ▼ 高保真训练数据 ┌──────────────────────────────────┐ │ Non-autoregressive CNN-Transformer│ │ (全局时序上下文, 抑制重建噪声) │ └──────────────────────────────────┘ vs 传统优化: 消除关节跳变, 减少自碰撞 下游效果: 全身控制策略收敛加速
核心 Insight: 传统优化 retarget 是非凸问题，容易陷入局部最优（关节跳变、穿模）。NMR 将问题从"优化最优解"转为"学习数据分布"，绕过非凸性。

2025.11

VIRAL: Large-Scale Visual Sim-to-Real

NVIDIA / CMU | He et al. | arXiv:2511.15200

大规模视觉 sim-to-real 框架。在仿真中联合训练视觉编码器和 RL 策略，通过大规模视觉域随机化实现真机视觉泛化。G1 真机验证视觉引导的 loco-manipulation。详见 RL 专题。

VIRAL 视觉 Sim-to-Real for G1: ┌──────────────────────────────────────────────┐ │ 仿真: 视觉编码器 + RL 策略联合训练 │ │ 大规模视觉域随机化 (光照/纹理/背景) │ │ │ │ 真机 G1: │ │ RGB ──► 视觉编码 ──► RL 策略 ──► 全身控制 │ │ 零样本视觉泛化 (无需真机视觉数据) │ └──────────────────────────────────────────────┘
核心 Insight: 足够大规模的视觉域随机化可以弥合 sim-to-real 视觉差距，使 G1 无需任何真机视觉数据即可完成视觉引导的 loco-manipulation。

Humanoid Badminton: Imitation-to-Interaction

SJTU | Chen et al. | arXiv:2602.08370

从"模仿者"进化为"击球者"。流形扩展策略将离散击球点泛化为稠密交互体积。首次实现人形机器人羽毛球技能零样本 sim-to-real 迁移。

渐进式 RL 框架: Phase 1: Mimic (模仿人类运动先验) │ AMP 对抗运动先验 + 紧凑状态表征 ▼ Phase 2: Striker (功能性击球) │ 流形扩展: 离散击球点 → 稠密交互体积 │ (解决专家演示稀疏问题) ▼ 零样本 Sim-to-Real → 真机羽毛球 技能: 挑球 (lift) + 吊球 (drop shot)
核心 Insight: 运动模仿（好看）和功能交互（能打到球）是两个不同目标。流形扩展策略将稀疏击球点泛化为连续交互空间，让 RL 探索从"模仿者"跃迁为"运动员"。
