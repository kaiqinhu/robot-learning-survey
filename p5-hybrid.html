混合范式: VLA + World Model + RL

2026 年最前沿方向 — 三大技术路线的融合

为什么需要混合?

单一范式各有硬伤，混合取长补短：

单一范式的局限: VLA: 语义理解强 ← 但 → 物理动力学弱，新环境泛化差 WAM: 物理预测强 ← 但 → 推理开销大，需大量视频数据 RL: 最优策略 ← 但 → 需 reward 设计，样本效率低 Diff: 稳定高效 ← 但 → 受限于演示水平，无法超越 混合范式 (2026 SOTA): ┌──────────────────────────────────────────────┐ │ Phase 1: VLM/Video Pre-train │ │ → 互联网规模的语义 + 物理先验 │ │ │ │ Phase 2: Imitation / Flow Matching Fine-tune │ │ → 任务特定的动作模式 │ │ │ │ Phase 3: RL Fine-tune (GRPO/PPO/POCO) │ │ → 超越演示水平 + 环境自适应 │ └──────────────────────────────────────────────┘ = LLM Pre-train → SFT → RLHF 的机器人版本!

三阶段训练范式: VLA + RL

2025.02 里程碑

π₀.5 (Physical Intelligence)

Physical Intelligence | Black et al. | arXiv:2504.16054

在 π₀ (VLM + Flow Matching) 基础上加入 RL 微调阶段。预训练提供通用操作能力，RL 在具体任务上提升成功率和鲁棒性。VLA + RL 混合的标志性工作。

π₀.5 三阶段训练流水线: ┌────────────────────────────────────────────────┐ │ Phase 1: VLM Pre-train (Internet-scale) │ │ Vision + Language → 语义理解 │ │ ▼ │ │ Phase 2: Flow Matching SFT (Robot data) │ │ Obs + Lang → Continuous Action (去噪生成) │ │ ▼ │ │ Phase 3: RL Fine-tune (Task-specific) │ │ Success reward → 超越演示水平 │ └────────────────────────────────────────────────┘ = LLM Pre-train → SFT → RLHF 的机器人完美映射
核心 Insight: π₀.5 证明了 LLM 领域的 "Pre-train → SFT → RLHF" 范式可以完整迁移到机器人控制。Flow Matching 作为 SFT 阶段提供连续动作生成能力，RL 微调阶段在不破坏预训练泛化性的前提下显著提升任务成功率。

2025.02 VLA+WM+RL

SC-VLA: Self-Correcting VLA

UESTC | Liu et al. | arXiv:2602.21633

三合一：VLA + 稀疏世界想象 + 自纠正。辅助预测头预测任务进度和未来轨迹趋势（稀疏想象），在线动作精炼模块基于预测重塑 dense reward。比最优 baseline 少用 16% 步数，成功率高 9%。

SC-VLA 三合一架构: ┌──────────────────────────────────────────────────┐ │ VLA Backbone (Vision-Language-Action) │ │ ┌──────────┐ │ │ │ obs+lang │──►┬──► Action Head ──► a_t │ │ └──────────┘ │ │ │ ├──► Progress Head ──► p_t (进度) │ │ │ │ │ └──► Trajectory Head ──► τ (趋势) │ │ (稀疏世界想象) │ │ ▼ │ │ ┌──────────────────────────┐ │ │ │ Online Action Refinement │ │ │ │ dense reward = f(p_t, τ) │ │ │ │ a_t' = refine(a_t, r) │ │ │ └──────────────────────────┘ │ └──────────────────────────────────────────────────┘ 效果: -16% 步数, +9% 成功率 vs best baseline
核心 Insight: 不需要完整的视频级世界模型——仅预测任务进度和轨迹趋势（稀疏想象）就足以构建 dense reward 信号，在推理时实时精炼动作，以极低开销获得世界模型+RL 的收益。

VLA + World Model

2025.11 Scaling Law

GEN-0: Embodied Foundation Model with Scaling Laws

Generalist AI | 270K 小时真实物理交互数据

首个在真实世界物理交互数据上确立可预测扩展定律的具身基础模型。基于 270K 小时多机器人数据训练，证明机器人领域的 scaling law 与 LLM 类似——模型性能随数据和参数量可预测提升。具身 AI 的 "GPT-3 时刻"。

GEN-0 具身 Scaling Law: ┌──────────────────────────────────────────────┐ │ 核心发现: 具身基础模型存在可预测 scaling law │ │ │ │ 数据: 270K 小时真实物理交互 │ │ ·多机器人平台 (臂/手/移动) │ │ ·多任务类型 (操作/导航/交互) │ │ │ │ Loss │ │ │ · │ │ │ ·· │ │ │ ··· │ │ │ ····· │ │ │ ··········· │ │ └─────────────────────── Data/Params │ │ │ │ 意义: LLM scaling law → 具身 AI scaling law │ │ = 投入更多数据/算力 → 可预测的能力提升 │ └──────────────────────────────────────────────┘
核心 Insight: GEN-0 证明机器人基础模型不是"炼丹"——性能随规模可预测增长。这为具身 AI 的工业化投资提供了理论依据，正如 GPT-3 的 scaling law 引爆了 LLM 竞赛。

2026.03 双系统

DIAL: System-2 World Modeling

HKU / XPENG | Chen et al. | arXiv:2603.29844

VLM 做 System-2 慢思考（潜在世界建模），轻量网络做 System-1 快执行。意图瓶颈设计让 VLM 只需预测高层意图，保留预训练知识。详见 WAM 专题。

DIAL 双系统 (混合视角): ┌──────────────────────────────────────────────┐ │ VLM (System-2) │ │ obs + lang ──► 预测潜在未来状态 z_t+k │ │ (不直接输出 action!) │ │ │ latent intent │ │ ▼ │ │ Motor Net (System-1) │ │ z_t+k + obs ──► action (低延迟) │ │ │ │ 混合价值: VLM 语义 + World Model 物理先验 │ │ + 轻量执行器 → 10x 更少 demo │ └──────────────────────────────────────────────┘
核心 Insight: 混合的关键在于分层——VLM 负责"想什么"(意图)，World Model 负责"会怎样"(预测)，轻量网络负责"怎么做"(执行)。各层各司其职，避免 VLM 被迫学习低层控制。
arXiv 2603.29844 →
2025.11 WM+偏好

NORA-1.5: World Model + Action Preference Reward

NTU Singapore | Hung et al. | arXiv:2511.14659

用世界模型生成不同动作的未来预测，然后通过动作偏好奖励（对比"好动作"和"坏动作"的预测结果）来训练 VLA。世界模型不直接参与推理，而是作为训练时的奖励信号源。

NORA-1.5 世界模型做奖励: ┌──────────────────────────────────────────────┐ │ 训练时: │ │ action_good ──► World Model ──► future_good│ │ action_bad ──► World Model ──► future_bad │ │ │ │ │ │ └── 偏好对比 ──► reward signal ─┘ │ │ │ │ │ VLA ◄─── RL 训练 │ │ │ │ 推理时: │ │ obs + lang ──► VLA ──► action │ │ (不需要世界模型! 零额外推理开销) │ └──────────────────────────────────────────────┘
核心 Insight: 世界模型最有价值的角色可能不是"推理时预测未来"，而是"训练时提供奖励"——它知道哪个动作会导致好结果，这个判断力通过 RL 蒸馏进 VLA。

2026.03 潜在WM

AtomVLA: Predictive Latent World Model Post-training

INFIFORCE / HKU | Sun et al. | arXiv:2603.08519

在 VLA 后训练阶段注入潜在世界模型。不生成像素级视频预测，而是在 VLA 的潜在空间内预测未来状态——开销极低但物理约束有效。后训练即可完成，不需修改预训练流程。

AtomVLA 潜在空间后训练: ┌──────────────────────────────────────────────┐ │ 预训练 VLA (不修改) │ │ ▼ │ │ 后训练: 添加潜在世界预测头 │ │ ┌────────────────────────────────────┐ │ │ │ VLA 隐层 ──► Latent Prediction Head│ │ │ │ ──► 预测 z_t+1, z_t+2 │ │ │ │ (潜在空间, 非像素!) │ │ │ └────────────────────────────────────┘ │ │ │ │ 推理时: 潜在预测提供物理约束 │ │ → 动作决策受"未来会怎样"的隐式引导 │ │ │ │ 优势: 后训练即可, 不改架构, 开销极低 │ └──────────────────────────────────────────────┘
核心 Insight: 给 VLA 注入世界模型能力不需要从头重新训练——后训练阶段添加潜在预测头即可。在潜在空间而非像素空间预测，避免了 WAM 的推理开销问题。
arXiv 2603.08519 →

World Model + RL

2026.03 WM+RL

DreamPlan: Video World Model RL Fine-tune

USC / TRI | Jia et al. | arXiv:2603.16860

在视频世界模型的"想象空间"中做 RL 训练，而非在真实/仿真环境中交互。世界模型生成虚拟 rollout，RL 在虚拟 rollout 上优化策略。大幅减少真机交互需求。

DreamPlan 想象空间 RL: ┌──────────────────────────────────────────────┐ │ 传统 RL: 策略 ←→ 真实环境 (昂贵/危险) │ │ │ │ DreamPlan: │ │ ┌────────────┐ ┌──────────────────────┐ │ │ │ Video World│ │ RL Policy │ │ │ │ Model │◄──│ │ │ │ │ │──►│ 在想象中优化 │ │ │ │ (虚拟环境) │ │ (无需真机交互!) │ │ │ └────────────┘ └──────────────────────┘ │ │ ▲ │ │ │ 少量真机数据校准世界模型 │ │ │ │ 优势: 无限虚拟 rollout + 安全 + 低成本 │ └──────────────────────────────────────────────┘
核心 Insight: 如果世界模型足够准确，RL 可以完全在"想象"中训练——这是 Dyna 架构在视频世界模型时代的复兴。关键挑战是世界模型的预测误差会被 RL 放大。

2026.02 WM+自适应

AdaWorldPolicy: Online Adaptive Diffusion Policy

HKU / Beihang | Yuan et al. | arXiv:2602.20057

部署时通过世界模型实时估计环境变化，在线自适应 Diffusion Policy。不需要重新训练——世界模型检测到环境偏移后，自动调整扩散策略的引导信号。

AdaWorldPolicy 在线自适应: ┌──────────────────────────────────────────────┐ │ 离线: 训练 Diffusion Policy + World Model │ │ │ │ 在线部署: │ │ ┌────────────────────────────────────┐ │ │ │ World Model 预测 vs 真实观测 │ │ │ │ 预测误差 → 环境偏移信号 │ │ │ │ │ │ │ │ │ ▼ │ │ │ │ 自适应引导 → 调整扩散去噪方向 │ │ │ │ │ │ │ │ │ ▼ │ │ │ │ Diffusion Policy → 适应后动作 │ │ │ └────────────────────────────────────┘ │ │ │ │ 无需重训练! 世界模型检测偏移 → 在线调整 │ └──────────────────────────────────────────────┘
核心 Insight: 世界模型的预测-观测误差本身就是环境变化的信号。利用这个信号在线调整扩散策略的引导方向，比重新训练或微调高效几个数量级。

2026.03 分层专家

MetaWorld-X: Hierarchical Expert + VLM Router

USTC | Shen et al. | arXiv:2603.08572

分治原则：将复杂控制分解为专家策略集合。每个专家通过模仿约束 RL 学习，引入生物力学先验。VLM 引导的智能路由机制动态组合专家。

MetaWorld-X 分层架构: ┌──────────────────────────────────────────────┐ │ VLM Router (语义层) │ │ obs+lang ──► 任务分解 → 子目标序列 │ │ [走过去] → [伸手] → [抓取] │ │ ▼ ▼ ▼ │ │ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ │ │Locomotion│ │ Reaching │ │ Grasping │ │ │ │ Expert │ │ Expert │ │ Expert │ │ │ │(RL+Bio) │ │(RL+Bio) │ │(RL+Bio) │ │ │ └──────────┘ └──────────┘ └──────────┘ │ │ 模仿约束 RL + 生物力学先验 │ └──────────────────────────────────────────────┘
核心 Insight: 全身控制可通过"专家分治+语义路由"降维——每个专家只解决一类运动原语，VLM 负责高层任务分解和专家调度。

2026 趋势总结

六大趋势

  1. Pre-train → SFT → RL 三阶段成为共识 — π₀.5 验证完整 LLM 训练范式可迁移
  2. World Model 双角色：训练时做奖励源 (NORA-1.5) 或推理时做预测器 (DIAL)
  3. RL 微调普适化：POCO 模型无关方案使 RL 微调适用于任何生成式策略
  4. 推理效率革命：从 100 步去噪 → 1 步 (DMPO >120Hz)，潜在空间替代像素空间 (AtomVLA)
  5. 在线自适应：世界模型实时检测环境偏移并调整策略 (AdaWorldPolicy)
  6. 跨具身迁移：30 分钟数据适应新机器人 (DreamZero)，运动学解耦 (KineVLA)
