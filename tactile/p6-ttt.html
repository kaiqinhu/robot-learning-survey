Test-Time Training: 前向传播中学习

快权重理论 / 方法谱系 / 2025-2026 关键突破 / 杀手级应用 / 机器人机会

摘要: 当前大模型在部署后权重冻结，所有适应局限于上下文窗口内的 In-Context Learning。Test-Time Training (TTT) 提出将学习折叠进前向传播——隐状态不再是固定规则更新的向量，而是一个可通过梯度下降更新的模型（快权重）。本综述从 Schmidhuber 1992 快权重到 2026 年 TTT/TTC 前沿，梳理 41 篇论文的方法谱系。核心结论：TTT 在长上下文（>8K）场景下困惑度持续改善（Mamba ~16K 饱和），3D 重建已成为杀手级应用（2026 初 6+ 篇），而 TTT × 机器人持续适应（涌现纠错）是最有潜力的蓝海方向。

1. 为什么需要 TTT：从瓶颈到快权重

大语言模型的部署范式有三个根本限制：适应能力受上下文窗口限制（ICL 容量有天花板），数据飞轮是离线的（用户反馈无法实时回流到权重），个性化缺失（同一模型面对所有用户）。核心问题：能否让模型在推理的每一步都进行某种形式的学习？

标准 Transformer 用 O(n²) 注意力实现"完美记忆"但计算不可承受；线性 RNN/SSM 用固定大小隐状态实现 O(n) 推理但记忆容量有限——困惑度在约 16K 后饱和。TTT 的核心洞察：隐状态本身就是一个模型（快权重），通过在前向传播中对每个 token 做梯度下降来更新记忆，让记忆容量不再受限于 d²，而是受限于内部模型的表达能力。

30 年理论积累

Schmidhuber (1992) 首次提出快权重概念：慢权重（预训练）决定更新规则，快权重（前向传播中更新）存储工作记忆。Ba & Hinton (2016) 将快权重具象化为外积关联记忆 A_t = λ·A_{t-1} + η·h_t·h_tᵀ——实际上就是带衰减的线性注意力。Schlag, Irie, Schmidhuber (2021) 正式建立等价关系 "线性 Transformer = 快权重编程器"，提出 Delta 规则修正累加式记忆的干扰问题——"先减去旧关联，再加上新关联" = 在线梯度下降的一步。从这里开始，"快权重"和"测试时学习"在数学上汇合了。

Von Oswald et al. (ICML 2023) 是真正的理论转折点：证明训练好的 Transformer 在做 ICL 时，其前向传播数学上等价于梯度下降。多层 Transformer = 多步梯度下降，且能学会预条件梯度下降（类似牛顿法）。Akyürek et al. (2023) 独立验证 ICL ≈ 岭回归，Ahn et al. (2024) 证明多头注意力能实现预条件 GD。这组工作的革命性意义：Transformer 的前向传播中已经有学习在发生——只不过是隐式的、受限的。TTT 的跳跃：既然已经在隐式做梯度下降，为什么不显式做？

MesaNet (DeepMind, 2025) 提出统一视角：所有序列模型都是在做某种"mesa-optimization"——状态更新就是"在前向传播中学习"，输出就是"用学到的模型预测"。差异在于状态表示（向量 → 矩阵 → 神经网络权重）、更新规则（固定线性 → 门控 → 梯度下降）、目标函数（无 → 隐式 → 显式自监督）、适应强度（均匀 → surprise 调制）和遗忘机制（无 → 衰减 → 学习的遗忘率）。

2. 方法谱系：从线性注意力到显式 TTT

按更新规则从简单到复杂，所有方法共享"快权重"本质。

累加式方法 (W += Δ) 是最简单的快权重。Linear Attention (2020) 用 O(n) 推理但不能遗忘、表征塌陷。RWKV (2023) 加入通道级指数衰减实现简单遗忘。RetNet (MSRA, 2023) 提供保留/循环/并行三种计算模式。GLA (MIT, 2024) 引入数据依赖门控矩阵。mLSTM/xLSTM (Hochreiter, 2024) 用矩阵记忆+指数门控，xLSTM 7B 是累加式方法的最大规模开源验证。累加式方法的共同局限：只能累加不能纠错，相同 key 不同时步存储不同 value 会互相干扰。

纠错式方法 (Delta Rule) 解决干扰问题。DeltaNet (MIT, 2024) 更新规则 W += β·k·(v - Wᵀk)ᵀ——"先读旧值，纠正后写入"，1.3B 规模训练 100B tokens 超越 Mamba 和 GLA。Gated DeltaNet (NVIDIA, 2024) 加入短卷积和 GLA 式门控，证明与线性注意力等价（dual form），是目前非 TTT 阵营最强方法。

显式 TTT（梯度下降更新） 是范式跳跃。TTT-Linear (Stanford, 2024.7) 开创性地将隐状态定义为可学习的线性层 W ∈ R^(d×d)，用重构损失做自监督。关键定理：在 batch GD、η=1/2、W₀=0 条件下 TTT-Linear 精确等价于线性注意力——建立了 TTT 与整个线性注意力家族的数学联系。TTT-MLP 将内部模型升级为 2 层 MLP（4x 扩展, GELU, LayerNorm, 8d² 参数），32K+ 上下文持续改善。Titans (Google, 2025.1) 引入 surprise 门控（梯度范数 = 意外程度，意外 token 强记忆），支持 2M 上下文，三种变体中 MAC（Memory as Context，记忆与注意力拼接）最强——混合架构优于纯替代。

3. 2025-2026 关键突破

TTT-E2E (Stanford, 2025.12) 是最颠覆性的发现：不需要设计特殊的 TTT 层，用标准 Transformer + 滑动窗口注意力，在测试时直接做 next-token prediction 继续学习。关键是通过元学习优化初始化 W₀——预训练时反向传播穿过内部 GD 步骤。3B 模型在 128K 上下文下困惑度匹配全注意力 Transformer，推理快 2.7×，恒定延迟。核心启示：关键不在架构，在于如何 meta-learn 初始化——没有元学习的 Mamba/DeltaNet 在 8-16K 后饱和，有了元学习初始化 TTT 能持续 scale。

LaCT / TTT Done Right (Adobe, 2025.5) 解决了工程瓶颈：发现 TTT 训练效率低的根因是 mini-batch 太小导致 GPU 利用率 <5%。解决方案是大 chunk 更新（2K-1M token），无需自定义 CUDA kernel。在 14B 视频扩散模型上验证，56K token 序列——当前最大规模 TTT 实践。这大幅降低了 TTT 的工程门槛。

MesaNet (DeepMind, 2025.6) 用共轭梯度法将 in-context loss 优化到最优（不止一步 GD），严格证明 DeltaNet、Mamba、xLSTM 的递推动力学全部来自近似优化同一个 in-context 回归目标。核心发现：增加推理计算 = 提升质量——与 test-time compute scaling 趋势一致。在 billion-parameter scale 超越此前所有 RNN。

TNT (Google, 2025.11) 解决 Titans 训练速度问题：两阶段训练（大 chunk 预训练 + 小 chunk 微调），训练速度提升 17×。ATLAS / DeepTransformers (Google, 2025.5) 针对 Titans 三个局限改进（容量有限→深层记忆网络；只看最近输入→联合优化；记忆管理不灵活→更有表达力的读写），是 Transformer 的严格泛化，BABILong 10M 上下文 +80% 准确度。

TTC (2026.3) 将 TTT 从"前向传播中记忆"推广到"前向传播中推理"：在推理时执行有限时域 LQR 规划。作为预训练 LLM 的 adapter，MATH-500 +27.8%，AMC/AIME Pass@8 提升 2-3×。开启新维度：内部优化目标可以是规划/控制，不限于记忆。

NVIDIA 的"祛魅" (2026.2) 论文标题直接说 "TTT with KV Binding Is Secretly Linear Attention"。证明一大类 TTT 架构可以表示为学习的线性注意力算子——TTT 不一定在做"测试时记忆"，而是在做增强表示能力的线性注意力。既是批评也是机会：可用线性注意力优化技巧加速 TTT。

其他重要工作：AllMem (Huawei, 2026.2) SWA+TTT 混合 128K 超越全注意力；Locas (2026.2) 参数化记忆可卸载/合并支持持续学习；OLMo Hybrid (AI2, 2026.4) 理论证明混合模型严格强于任一单独；In-Place TTT (2026.4) 解决 TTT 与当前 LLM 生态的架构不兼容问题。

4. 杀手级应用与实验结果

3D 重建：2026 年爆发

TTT 已成为流式 3D 重建的默认架构选择——2026 初至少 6 篇论文（tttLRM、Mem3R、Spatial-TTT、ZipMap、VGG-T³、Scal3R）。原因：从视频流持续压缩视觉观测到快权重，天然匹配"前向传播中学习"范式。Mem3R 轨迹误差 -39%，所有方法都实现了线性时间复杂度的有状态 3D 重建。这是 TTT 从理论走向工程的第一个大规模成功案例。

视频生成

Stanford+NVIDIA (2025.4) 将 TTT 层嵌入 5B Transformer，从文本故事板生成一分钟连贯视频，人工评测 +34 Elo 优于 Mamba-2、Gated DeltaNet、滑动窗口注意力。LaCT 在 14B 视频扩散模型上验证了 TTT 处理极长视频序列的能力。

机器人：涌现纠错能力

EVOLVE-VLA (2025.12) 是目前唯一的 TTT × 机器人工作。TTT 框架用于 VLA 模型，通过环境交互持续适应：长程任务 +8.6%，1-shot 学习 +22%，未见任务 20.8% 成功率（SFT 为 0%）。最关键发现：展现了训练数据中不存在的涌现纠错能力——模型在推理时"学会"从错误中恢复。这暗示 TTT 的"前向传播中学习"机制可以产生训练时未见过的行为。

5. 硬件挑战与批评

TTT 的核心工程挑战是前向传播中需要 backward pass——每个 token 都要做一次梯度计算来更新内部模型。这导致 FLOPs 利用率低（mini-batch 太小，GPU <5%）、显存 3-4×（需存 optimizer state + gradients）、训练速度慢。LaCT 证明大 chunk 更新（2K-1M token）可以无需自定义 CUDA kernel 达到高利用率，TNT 两阶段训练实现 17× 加速，In-Place TTT (2026.4) 正在解决与 LLM 生态的架构不兼容问题。趋势是清晰的：自定义 kernel 不再必要，标准 PyTorch 即可实现高效训练。

已知批评中最有分量的是 NVIDIA (2026.2) 的"祛魅"——证明一大类 TTT 本质是学习的线性注意力，多个现象与"记忆"叙事矛盾。TTT-E2E 发现没有元学习的 Mamba/DeltaNet 无法随上下文 scale，暗示原始 TTT 的成功可能更多来自初始化而非架构。MesaNet 提出更多推理计算 = 更好质量，将"推理成本高"转化为特性而非缺陷。

TTT 无效的场景：短上下文 (<1K) 标准注意力已足够、平稳分布无需适应、噪声数据浪费算力"学习"噪声、1D 序列假设不适合图像/视频（LaCT 用大 chunk 缓解）。稳定性方面，内部学习率敏感（过高不稳定、过低无适应）、TTT-MLP 多步更新可能梯度爆炸、超长序列内部模型漂移远离初始化。Titans 的 surprise 门控 + 权重衰减 + 动量缓解但未完全解决。

6. 行业格局与机器人机会

TTT 领域形成了几个清晰的阵营。Stanford/UCSD (Yu Sun) 是开创者，从 TTT 原始到 TTT-E2E 再到视频生成，最大验证 5B。Google Research (Behrouz) 贡献了 Titans/TNT/ATLAS 系列架构创新。Google DeepMind (Von Oswald) 提供理论统一（MesaNet）。NVIDIA 从硬件效率角度推进（Gated DeltaNet + 理论分析），同时提供"祛魅"式批评。Adobe 在视频扩散上验证了最大规模（14B）。NXAI (Hochreiter) 推动 xLSTM 7B 开源。3D Vision 社区是最活跃的应用阵营。

开放问题与未来方向

架构设计空间仍然广阔：自监督目标只探索了重构损失（对比学习、预测编码未试）；内部模型只有线性/2层MLP（稀疏 MLP、LoRA 未试）；TTT × MoE 完全未探索——不同 expert 对应不同内部学习策略；TTC 从记忆到推理的推广才刚开始。学习动力学方面，TTT-E2E 证明元学习初始化是关键但更好的方法未知，多尺度适应（不同层处理不同时间尺度）未探索。

与力觉世界模型 (FWM) 的交叉

TTT 与 FWM 存在天然互补。FWM 执行层 (100-1000Hz) 的力觉 RL Tracker 需要实时适应环境变化——TTT 的"前向传播中学习"天然匹配。FWM 规划层 (10-30Hz) 的力觉世界模型预测 F_{t+1}——TTT 内部模型可作为动态转移函数，快权重在接触过程中持续适应材料属性。TTC 的 LQR 规划能力可直接应用于力觉轨迹优化。EVOLVE-VLA 的涌现纠错能力更是令人兴奋——力觉反馈提供最直接的"错误信号"，TTT × 力觉可能产生更强的涌现纠错。

核心机会：TTT × 机器人目前仅有 EVOLVE-VLA 一篇，且未涉及触觉/力觉。TTT + 力觉世界模型是一个完全空白的交叉方向。
