评测体系：Benchmark 与比赛全景

仿真评测 / 真机评测 / 触觉评测 / 人形机器人 / 比赛 / 系统性问题

摘要: 本章系统梳理 2024-2026 年机器人操作领域的评测体系全景。仿真侧，LIBERO/Calvin/RLBench 等经典基准持续演进，ManiSkill 3 以 30,000+ FPS 实现 GPU 并行评测，RADAR/ManipArena 等新基准将评测从简单成功率扩展到推理和物理直觉。真机侧，RoboChallenge 首创"远程机器人"范式——全球任何人可通过 HTTP API 远程调用 10 台真实机器人进行标准化评测，即使最强的 π₀.₅ task-specific 也只有 44% 成功率。触觉评测仍处于早期阶段，力觉世界模型的预测质量评测完全空白。Benjie's Humanoid Olympic Games 精准暴露了当前学习范式在力反馈、触觉感知和手指控制方面的系统性短板。

1. 仿真评测 Benchmark 全景

仿真评测可分为四个层次，各有侧重。

通用操作基准是基础设施。LIBERO (UT Austin, 2023) 以 130 个终身学习任务和 4 个知识迁移套件成为 VLA 标准评测之一，2026 年的 LIBERO-Plus 扩展增加了语言/视觉扰动评测 OOD 鲁棒性。Calvin (Freiburg, 2022) 考察 34 个任务的连续指令执行，VPP 报告 +18.6% 泛化。RLBench (Dyson Lab, 2020) 100 个任务 × 18 变体/任务是标准 3D 操作基准。ManiSkill 3 (UCSD Hao Su Lab, 2024) 以 30,000+ FPS GPU 并行仿真和 20+ 任务类别代表了高吞吐评测方向。GRUtopia (Shanghai AI Lab, 2024) 则走向城市级仿真——100K 场景、89 类环境、LLM NPC。

VLA 专项评测是 2026 年的新趋势。SIMPLER (Google, 2024) 对齐真实 WidowX/Franka 设置评估 sim-real 一致性。RADAR (多校联合, 2026) 首次系统评估 VLA 在动态变化环境下的鲁棒性和物理推理能力。ManipArena (2026) 强调语义推理而非纯运动执行。ManipulationNet (2026) 评测物理直觉。WAM-vs-VLA (蚂蚁/浙大, 2026) 在 LIBERO-Plus 和 RoboTwin 2.0-Plus 上做了首次系统的跨范式对比。

双臂/协作/装配方面，RoboTwin 2.0 是 GigaWorld/WAM 的评测标准，FurnitureBench (2023) 考察长序列家具组装，NIST Assembly Task Board 是政府标准化工业装配基准（齿轮/USB/连接器）。移动操作方面，MobileManiBench (2026) 评测移动底盘+操作臂联合，AffordSim (2026) 评测可供性感知。

2. RoboChallenge：大规模真机在线评测

RoboChallenge 是首个大规模真机在线评测系统，其"远程机器人"范式解决了真机评测的可扩展性和可复现性问题。核心创新：用户不需要提交模型权重/Docker——通过 HTTP API 远程调用机器人，发送 capture request 获取精确时间戳的观测（RGB+深度+本体感受），提交 action 到队列，模型推理完全在用户侧完成。支持任意控制策略（包括需要精细时间控制的 Real-Time Action Chunking），NAT 友好无需公网 IP。硬件平台包括 10 台机器人 4 种类型：UR5（6-DOF, Robotiq 夹爪, RTDE 接口最高 125Hz）、Franka Panda（7-DOF, 双模式控制）、Cobot Magic Aloha（双 6-DOF, 移动平台）、ARX-5（6-DOF, 性价比高）。

3. 触觉评测：早期阶段与空白地带

触觉评测远落后于视觉评测的成熟度。TacBench (Meta, Sparsh 2024) 是第一个系统性触觉表征评测——6 个任务（抓取稳定性、表面分类、姿态估计等），核心发现 DINO/IJEPA 优于 MAE。UniVTAC Benchmark (2025) 扩展到 8 个视触觉任务，验证仿真→真机提升 17.1%(仿真)/25%(真实)。ManiFeel (2025) 是首个视触觉操作策略学习基准，评测触觉对哪些任务有用。

G1 Sensor Benchmark (Hannover, 2026, arXiv:2603.28422) 对比了 14 种传感器组合，发现了一个违反直觉的结论：数据有限时传感器越多反而越差（87.5%→67.3%）——更多模态意味着更大的特征空间，有限数据下模型无法有效利用。VITaL 触觉消融证明 USB 插拔训练加触觉即使推理时移除仍从 20%→85%。AnyRotate 验证了触觉 sim2real 可行性。

空白地带：TacBench 考察触觉表征质量，ManiFeel 考察视触觉策略，但零个评测集考察力觉动力学预测或力觉世界模型质量。FWM 的预测误差增长曲线（N 步后误差如何积累）、力觉 rollout 与真实轨迹的一致性、不同材质/接触模式下的预测鲁棒性——这些都需要全新的评测框架。

4. 人形评测与国际国内比赛

人形机器人评测正在快速标准化。AGILE (ETH Zurich, 2026, arXiv:2603.20147) 覆盖全生命周期（环境验证→训练→评测→部署），已在 G1 和 Booster T1 验证。MetaWorld-X (USTC, 2026) 用分治法编排运动/伸手/抓取专家，VLM 路由器调度。HumanoidBench (2024) 提供 15+ 人形全身操作+运动评测。NVIDIA Isaac Lab 是训练框架标准，GPU 加速支持 G1/Go2 URDF。

国际比赛方面，RoCo Challenge (AAAI 2026) 聚焦双臂协作装配面向工业自动化；ManiSkill Challenge (CVPR/CoRL) 以高吞吐 GPU 并行评测为特色；ICRA Manipulation 是年度传统旗舰；RoboCup@Home 侧重服务机器人系统集成。国内方面，WRC 世界机器人大赛（中国电子学会）规模最大，2025-26 年各省市/高校新设的具身智能专项赛正在兴起。

Benjie's Humanoid Olympic Games：暴露系统性短板

由机器人研究者 Benjie Holson 发起的社区挑战赛，以铜/银/金三级奖章制考察人形机器人在真实家庭场景中的操作极限。规则：1× 速度无剪辑视频，通用移动操作机器人自主运行，允许 10× 人类用时。

Holson 明确指出当前范式的 4 个核心限制中 3 个直接与力/触觉相关："No force feedback at the wrists"（遥操作者感受不到力）、"No sense of touch"（人手布满传感器，机器人手几乎没有）、"Limited finger control"（多数任务只能 open/close）。第 4 个是精度限制（1-3cm）。15 个任务中绝大多数需要力觉世界模型才能根本性解决。

5. 评测体系的系统性问题

当前评测生态存在严重碎片化和结构性缺陷。

基准割裂：VLA 用 SIMPLER/Calvin，WAM 用 RoboTwin，RL 用 Isaac Lab——跨范式对比几乎不可能。WAM-vs-VLA (蚂蚁/浙大, 2026) 是首次系统尝试，但仅覆盖两个范式。试验量不足：多数论文 10-100 次试验无置信区间，RoboChallenge 证实同一模型+任务成功率可在 0-100% 波动。OOD 评测缺乏：多数基准测试分布内性能，RADAR/ManipArena 正在填补这一空白。真实部署指标缺失：基准衡量单次成功率，部署需要 MTBF、故障恢复率、长尾覆盖率。

触觉与力觉评测完全空白是最大的结构性缺陷。尚无公认的触觉操作基准，力觉预测评测零个。测试人员偏差（"sweet spot effect"）可系统性偏置结果——RoboChallenge 的盲测 Comparative Protocol 是缓解方案之一。

2026 年新趋势：VLA 评测专项化（RADAR/ManipArena 超越简单成功率评测推理和物理直觉）；真机大规模评测成为可能（RoboChallenge 的远程机器人范式打破物理限制）；协作与装配评测兴起（RoCo Challenge 标志评测从单臂桌面转向双臂工业协作）；自主评估方法（RADAR/ROBOGATE 尝试自动化评测减少人工依赖）。
