里程碑演进

2019

Sim-to-Real for Dexterous Hand (OpenAI)

5000 年仿真经验 + massive domain randomization → 魔方复原。证明 sim-to-real 大规模可行性。

2022

AMP (Adversarial Motion Priors)

用 GAN 判别器替代手工自然性 reward。人类动捕数据 → 判别器 → style reward。成为人形运动 RL 的标配。

2023

Agility Robotics Digit / Tesla Optimus RL

工业级人形机器人开始采用 sim-to-real RL。Teacher-Student + domain randomization 成为标准 pipeline。

2024-2025

BeyondMimic / ASAP — 超越模仿与 Sim2Real 对齐

BeyondMimic (CMU): 超越单纯运动模仿，实现多功能人形控制（操作+运动+恢复），被 5 篇 2026 论文引用。ASAP (Tencent): 系统对齐仿真与真实物理参数，解决 sim-to-real gap 的根因。

2024

Isaac Lab + Unitree G1/H1 生态爆发

NVIDIA Isaac Lab 提供标准化训练框架，Unitree 低成本硬件降低门槛。人形 RL 论文数量爆增。

2025.12

15 分钟学会人形运动

GPU 加速 RL 将 sim-to-real 时间从数天压缩到 15 分钟。极速迭代成为可能。

2026.03

G1 Running 3.3m/s / BAT / HALO / AGILE

人形跑步速度记录 + 敏捷-稳定切换 + 重载可微仿真 + 标准化工作流。RL sim-to-real 全面成熟。

Multi-Objective Reward 设计

人形步态 RL 的 reward 设计天然是多目标的，与 LLM RLVR 中的 multi-rubric 高度对应：

Reward Domain具体项权重趋势
稳定性 Stability 躯干姿态偏差、ZMP 边距、角动量变化率、质心高度 高权重，安全底线
运动质量 Locomotion 速度跟踪、步态对称、步频平滑、足底接触过渡 核心任务 reward
能耗效率 Energy 力矩平方积分(CoT)、机械功、电流峰值、无效运动 中权重，工程考量
安全约束 Safety 关节极限、速度上限、自碰撞、跌倒终止罚、GRF 上限 硬约束/高惩罚
自然性 Naturalness 动作平滑(Δaction)、参考动作距离、AMP 判别器 AMP 替代手工调

Reward 冲突矩阵

稳定性 ◄── 冲突 ──► 运动速度 (走快=不稳) 能耗 ◄── 冲突 ──► 任务完成 (省力≠高效完成) 安全 ◄── 冲突 ──► 运动范围 (保守=功能受限) 自然性 ◄── 冲突 ──► 能耗效率 (好看≠省力) → 与 LLM RLVR 中 correctness vs conciseness 完全类比 → 你的 per-rubric PPO clip 框架可直接迁移!

arXiv:2604.01064

BAT: Policy-Switching for Humanoid

Georgia Tech | Baek et al. | arXiv:2604.01064

在线策略切换框架：动态在两个互补全身 RL 控制器之间切换，平衡敏捷性和稳定性。层次 RL + 滑动视窗策略预评估 + 基于 VQ-VAE 的运动偏好预测。

BAT 在线策略切换: ┌──────────────────────────────────────────────┐ │ Policy A: 敏捷控制器 (速度优先) │ │ Policy B: 稳定控制器 (安全优先) │ │ │ │ ┌──────────────────┐ │ │ obs ──► │ Meta-Controller │ ──► 选择 A or B │ │ │ ·滑动视窗评估 │ │ │ │ ·VQ-VAE 偏好预测 │ │ │ └──────────────────┘ │ │ │ │ 关键: 不是混合输出, 而是硬切换 │ │ → 避免两个策略互相干扰 │ │ → 长时域 loco-manipulation G1 真机验证 │ └──────────────────────────────────────────────┘
核心 Insight: 单一 RL 策略难以同时兼顾敏捷性和稳定性（reward 冲突）。BAT 用两个专精策略 + 元控制器硬切换，比混合策略更有效。

ABD-Net: Physics-Informed GNN

UT Austin / UW-Madison | Shin et al. | arXiv:2603.19078

将关节体动力学算法 (ABA) 的惯量传播机制嵌入 GNN。物理信息表征捕获动作如何在身体中传播。采样效率提升 + 动力学偏移泛化 + G1/Go2 真机实时推理验证。

ABD-Net 物理信息 GNN: ┌──────────────────────────────────────────────┐ │ 传统 RL: MLP(obs) → action │ │ 问题: 不理解身体拓扑结构 │ │ │ │ ABD-Net: 关节体动力学 + GNN │ │ ┌─────┐ ┌─────┐ ┌─────┐ │ │ │ 关节1│──│ 关节2│──│ 关节3│ ← 身体拓扑图 │ │ └──┬──┘ └──┬──┘ └──┬──┘ │ │ │ ABA 惯量传播 │ │ │ └───────┬────────┘ │ │ ▼ │ │ 物理感知表征 → 动作预测 │ │ │ │ 优势: 换机器人只需换拓扑图, 表征可迁移 │ └──────────────────────────────────────────────┘
核心 Insight: 机器人身体是树结构——力从末端传播到根。ABD-Net 把这个物理先验编码进 GNN 的消息传递中，而非让 MLP 从数据中重新学习。

arXiv:2603.15084

HALO: Heavy-Load Humanoid via Differentiable Sim

ZJU / TeleAI | Wang et al. | arXiv:2603.15084

针对重载人形机器人（搬运、负重行走）的 sim-to-real 方案。可微仿真器提供解析梯度，加速策略优化。通过 contact-aware 自适应补偿真机接触动力学差异。真机验证负重 20kg 稳定行走。

HALO 可微仿真 Sim-to-Real: ┌──────────────────────────────────────────────┐ │ 传统: PPO (采样梯度, 方差大, 慢) │ │ HALO: 可微仿真器 (解析梯度, 精确, 快) │ │ │ │ ┌────────────┐ ∂reward/∂action │ │ │ 可微仿真器 │ ──────────────────► 策略更新 │ │ │ (解析梯度) │ 无需 PPO 采样! │ │ └────────────┘ │ │ + │ │ Contact-Aware 补偿: │ │ 仿真接触 vs 真机接触 → 在线适应 │ │ │ │ 真机: 负重 20kg 稳定行走 │ └──────────────────────────────────────────────┘
核心 Insight: PPO 的零阶梯度估计是 sim-to-real 训练的瓶颈之一。可微仿真提供精确梯度，但代价是接触动力学的不可微问题——HALO 用自适应补偿绕过此限制。

SLowRL: Safe LoRA Fine-tuning on Real Robot

McGill / Mila / TU Munich | Daneshmand et al. | arXiv:2603.17092

解决真机 RL 微调的安全问题。LoRA (rank-1!) + recovery policy 安全约束。微调时间减少 46.5%，安全违规近零。证明极低秩适应即可弥合 sim-to-real gap。

SLowRL 安全真机微调: ┌──────────────────────────────────────────────┐ │ 问题: sim-to-real gap → 真机需要微调 │ │ 但真机微调 → 可能摔坏机器人! │ │ │ │ SLowRL 解法: │ │ ┌──────────────┐ ┌──────────────────┐ │ │ │ 冻结策略 │ + │ LoRA rank-1 适配 │ │ │ │ (sim 预训练) │ │ (极少参数微调) │ │ │ └──────────────┘ └──────────────────┘ │ │ + │ │ ┌─────────────────────────────────────┐ │ │ │ Recovery Policy: 检测危险 → 接管 │ │ │ │ (安全约束, 违规率 ≈ 0) │ │ │ └─────────────────────────────────────┘ │ │ 效果: 微调时间 -46.5%, 安全违规近零 │ └──────────────────────────────────────────────┘
核心 Insight: Sim-to-real gap 可能只需要极少的参数调整（rank-1 LoRA!）。大部分 sim 策略是正确的，gap 集中在少数物理参数不匹配的维度上。

BeyondMimic: 超越模仿的多功能人形控制

CMU | Cheng et al.

突破传统运动模仿 RL 的单一任务局限。训练单一策略同时支持行走、跑步、跳跃、搬运、恢复等多种技能，并能在技能间平滑切换。被 5 篇 2026 论文引用，是人形 RL 从"模仿单个动作"走向"通用运动能力"的标志性工作。

BeyondMimic 多功能控制: ┌──────────────────────────────────────────────┐ │ 传统运动 RL: │ │ 一个策略 = 一个技能 (走 or 跑 or 搬) │ │ │ │ BeyondMimic: │ │ ┌─────────────────────────────────────────┐│ │ │ Single Versatile Policy ││ │ │ ┌─────┐ ┌─────┐ ┌─────┐ ┌──────────┐ ││ │ │ │Walk │ │Run │ │Jump │ │Loco-Manip│ ││ │ │ └──┬──┘ └──┬──┘ └──┬──┘ └────┬─────┘ ││ │ │ └───────┴───────┴─────────┘ ││ │ │ 平滑技能切换 ││ │ └─────────────────────────────────────────┘│ │ 关键: 共享低层运动原语 + 高层技能调度 │ └──────────────────────────────────────────────┘
核心 Insight: 人类的运动能力不是一组离散技能，而是连续运动流形上的不同区域。BeyondMimic 学习这个流形，使技能切换成为流形上的平滑移动而非硬切换。
2025 3x cited

ASAP: 对齐仿真与真实物理

Tencent | He et al.

系统性解决 sim-to-real gap 的根因——仿真器物理参数与真实世界不匹配。自动化物理参数辨识 + 在线校准流程，使仿真动力学更贴近真实。被 3 篇 2026 论文引用，是 domain randomization 之外的互补方案。

ASAP vs Domain Randomization: ┌──────────────────────────────────────────────┐ │ Domain Randomization: │ │ "不知道真实参数 → 随机化所有参数" │ │ 问题: 过度随机化 → 性能下降 │ │ │ │ ASAP: │ │ "精确辨识真实参数 → 对齐仿真器" │ │ 真机数据 → 系统辨识 → 修正仿真物理 │ │ → 更小的 sim-real gap → 更好的迁移 │ │ │ │ 互补: ASAP 缩小 gap + DR 覆盖残余不确定性 │ └──────────────────────────────────────────────┘
核心 Insight: Domain Randomization 是"承认无知"的暴力方案，ASAP 是"减少无知"的精确方案。两者互补：先用 ASAP 对齐核心物理参数，再用 DR 覆盖残余不确定性。

Adversarial Motion Priors (AMP)

AMP 是 2023-2026 年替代手工自然性 reward 的主流方法：

AMP 原理: ┌────────────┐ ┌──────────────────┐ │ 人类动捕数据│ ──► │ Discriminator │ ← 判别 "是否像人类" └────────────┘ │ D(s, s', a) │ └────────┬─────────┘ │ style reward ▼ ┌────────────┐ ┌──────────────────┐ │ 仿真环境 │ ──► │ RL Policy │ ← task reward + style reward └────────────┘ │ π(a|s) │ └──────────────────┘ 优势: 无需手工调节 "自然性" reward 权重 最新进展: NMR (2603.22201) 用 VAE 聚类 + CNN-Transformer 学习数据分布
