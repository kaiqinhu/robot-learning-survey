什么是 WAM?

World Action Model (WAM) 是 2025 年涌现的新范式。核心思想：先学会预测世界如何变化，再从预测中解码出动作。与 VLA 直接从视觉语言到动作的映射不同，WAM 引入了"想象未来"的中间过程。

VLA 路径 (直接映射) ┌──────────┐ ┌──────────┐ │ 观测+语言 │ ──► │ Action │ └──────────┘ └──────────┘ WAM 路径 (世界模型中介) ┌──────────┐ ┌──────────────┐ ┌──────────┐ │ 观测+语言 │ ──► │ 预测未来状态 │ ──► │ Action │ └──────────┘ │ (视频/latent) │ └──────────┘ └──────────────┘ │ 物理动力学先验 (来自视频预训练)

WAM vs VLA 关键差异

DreamZero: Zero-Shot World Action Model

KAIST / Google DeepMind | Ye et al. | arXiv:2602.15922

基于预训练视频扩散模型构建 WAM。联合建模视频和动作，学会物理动力学。

DreamZero 架构: ┌──────────────────────────────────────────────────┐ │ Pre-trained Video Diffusion Model (14B) │ │ ┌────────────┐ │ │ │ obs + lang │──► Joint Video-Action Modeling │ │ └────────────┘ ┌───────────┐ ┌───────────┐ │ │ │ Future │ │ Action │ │ │ │ Video │ │ Sequence │ │ │ └───────────┘ └───────────┘ │ └──────────────────────────────────────────────────┘ 关键数据: · 零样本泛化: 比 SOTA VLA 提升 2x+ · 跨具身迁移: 仅需 30 min play data → 保留零样本能力 · 系统优化: 14B 自回归模型 → 7Hz 闭环 (原本不可能实时)
核心 Insight: 视频扩散模型预训练学到的时空动力学先验是 WAM 泛化能力的关键来源。VLA 只看静态图文对，WAM 看过无数"物体运动的视频"——这个先验差异导致 2x 泛化差距。

2026.03 效率突破

GigaWorld-Policy: Action-Centered WAM (9x Faster)

GigaAI | GigaAI Team | arXiv:2603.17240

解决 WAM 推理慢的核心瓶颈——将动作预测和视频生成解耦。

GigaWorld 因果分离设计: 训练时 (双重监督): ┌─────────┐ Causal Transformer │ obs+lang│──►┌────────────────────────────────┐ └─────────┘ │ [Action Tokens] ──► [Video Tokens]│ │ ↓ L_action ↓ L_video │ └────────────────────────────────────┘ 关键: video tokens ──╳──► action tokens (因果掩码: 视频不影响动作) 推理时 (跳过视频): ┌─────────┐ ┌──────────────────┐ │ obs+lang│──►│ Action Tokens Only│ ← 9x 加速! └─────────┘ └──────────┬───────┘ ▼ Robot Actions 对比: 速度 成功率 (RoboTwin 2.0) Motus (WAM): 1x base baseline GigaWorld: 9x faster +7% π₀.5 (VLA): — GigaWorld +95% over π₀.5
核心 Insight: WAM 不必在推理时生成视频。训练时视频生成提供物理约束监督信号，推理时只需动作解码即可——因果掩码保证两者解耦。"训练时想象，推理时直觉"。

2025.06 潜在空间

V-JEPA 2: Self-Supervised Video → Planning

Meta FAIR | Assran et al. | arXiv:2506.09985

将 V-JEPA（视频联合嵌入预测架构）扩展为动作条件化世界模型。在潜在嵌入空间内预测未来视频表征，完全不生成像素。比像素空间预测快数十倍，同时保留足够结构支持机器人规划和控制。

V-JEPA 2 潜在空间预测: ┌──────────────────────────────────────────────┐ │ 像素空间 WAM (DreamZero): │ │ obs → 生成未来视频帧 → 解码动作 │ │ 问题: 生成像素开销大, 大部分像素无用 │ │ │ │ V-JEPA 2 (潜在空间): │ │ obs ──► Video Encoder ──► z_t (嵌入) │ │ │ │ │ Predictor ──► ẑ_t+k (预测嵌入) │ │ │ │ │ 不生成像素! 直接在嵌入空间预测 │ │ → 保留语义+动力学信息 │ │ → 丢弃无关像素细节 (光影/纹理) │ │ │ │ 优势: 10-100x 更快 + 对视觉扰动天然鲁棒 │ └──────────────────────────────────────────────┘
核心 Insight: WAM 不需要"看见"未来——只需"理解"未来。JEPA 在嵌入空间预测，丢弃了像素级细节（光影、纹理），保留了决策所需的语义和动力学信息。这解释了为什么潜在空间 WAM 对视觉扰动更鲁棒。

2025.09 无动作预训练

LAWM: Latent Action Pretraining from Video

Adelaide | Tharwat et al. | arXiv:2509.18428

从无动作标签的纯观测视频中学习世界模型。自动推断帧间"潜在动作"，用于预训练动力学模型。下游只需少量动作标注数据即可微调为完整 WAM。解锁互联网规模视频作为 WAM 预训练数据源。

LAWM 潜在动作推断: ┌──────────────────────────────────────────────┐ │ 传统 WAM 预训练: │ │ 需要 (video, action) 配对数据 ← 昂贵! │ │ │ │ LAWM: │ │ frame_t ──► Latent Action Encoder ──► ẑ_a │ │ frame_t+1 ◄─┘ (推断帧间"发生了什么") │ │ │ │ ẑ_a = 潜在动作 (无需真实动作标签) │ │ │ │ World Model: f(z_t, ẑ_a) → z_t+1 │ │ 在潜在动作空间预训练动力学模型 │ │ │ │ 下游微调: │ │ 潜在动作 ẑ_a ←对齐→ 真实动作 a │ │ 少量配对数据即可 (100x less) │ └──────────────────────────────────────────────┘
核心 Insight: 互联网上有无限视频但几乎没有动作标签。LAWM 证明可以先从纯视频学到"世界如何变化"的动力学，再用少量机器人数据对齐"什么动作导致了变化"——数据效率提升两个数量级。

2025.08 3D 结构化

GWM: Gaussian World Models for Manipulation

Tsinghua / BIGAI / NTU | Lu et al. | arXiv:2508.17600

用 3D Gaussian Splatting 替代 2D 视频作为世界模型的核心表征。世界状态表示为 3D 高斯点云，动作导致高斯点的变形和运动。天然支持任意视角渲染、遮挡推理和 3D 空间规划。

GWM 3D 高斯世界模型: ┌──────────────────────────────────────────────┐ │ 2D 视频 WAM: │ │ 观测: 2D 图像 → 预测: 2D 未来帧 │ │ 问题: 视角固定, 遮挡无法推理, 无 3D 理解 │ │ │ │ GWM (3D Gaussian): │ │ 观测 → 重建 3D 高斯场景 │ │ ┌──────────────────────────────┐ │ │ │ · · · 3D Gaussians │ │ │ │ · ·· · · (位置+颜色+ │ │ │ │ · · ·· 形状+不透明度) │ │ │ └──────────────────────────────┘ │ │ 动作 → 高斯变形 → 新场景 │ │ 任意视角渲染 + 遮挡推理 + 3D 规划 │ │ │ │ 优势: 多视角免费, 3D 空间推理原生支持 │ └──────────────────────────────────────────────┘
核心 Insight: 2D 视频 WAM 本质上在"看照片预测照片"，丢失了 3D 空间信息。3D 高斯表征让世界模型直接在 3D 空间中推理——遮挡、深度、多视角都成为免费副产品。

2024.05 自回归

iVideoGPT: Autoregressive Tokenized World Model

Tsinghua | Wu et al. | arXiv:2405.15223

将视觉观测、动作和奖励统一 token 化为同一序列，用 GPT 自回归预测。与扩散 WAM 的"去噪生成"不同，iVideoGPT 用"下一 token 预测"建模世界动力学。天然继承 LLM 的 scaling law 和基础设施。

iVideoGPT vs 扩散 WAM: ┌──────────────────────────────────────────────┐ │ 扩散 WAM (DreamZero): │ │ noise → 多步去噪 → 未来视频+动作 │ │ 优点: 高质量生成 缺点: 多步推理慢 │ │ │ │ iVideoGPT (自回归): │ │ VQ-VAE 编码: │ │ [obs_tokens][action_tokens][reward_tokens] │ │ ↓ 统一序列 │ │ GPT: [..., v_t, a_t, r_t, v_t+1, ...] │ │ next-token prediction │ │ │ │ 优点: scaling law 适用, 基础设施复用 │ │ 优点: 序列建模天然支持长程依赖 │ │ 缺点: VQ 离散化损失细节 │ └──────────────────────────────────────────────┘
核心 Insight: 世界模型和 LLM 本质上都是"预测下一个 token"——iVideoGPT 证明将视觉/动作/奖励统一 token 化后，LLM 的 GPT 架构和 scaling law 可以直接迁移到世界建模。

2026.03 意图建模

DIAL: Differentiable Latent Intent Bottleneck

HKU / XPENG | Chen et al. | arXiv:2603.29844

将世界建模重构为 System-2 慢思考 + System-1 快执行的双系统架构。

DIAL 双系统架构: ┌─────────────────────────────────────────────┐ │ System-2 (VLM): Latent World Modeling │ │ ┌────────┐ ┌──────────────────────┐ │ │ │obs+lang│──►│ Predict Latent Future │ │ │ └────────┘ │ (VLM 特征空间内) │ │ │ └──────────┬───────────┘ │ │ │ latent intent │ │ │ (意图瓶颈) │ └─────────────────────────┼─────────────────┘ ▼ ┌─────────────────────────────────────────────┐ │ System-1 (轻量网络): Motor Execution │ │ latent intent + current obs → actions │ │ (Latent Inverse Dynamics) │ └─────────────────────────────────────────────┘ 两阶段训练: Phase 1: 解耦预热 — S2 学预测 + S1 学控制 (统一特征空间) Phase 2: 端到端联合优化 — action 梯度可微地优化 VLM

关键参考文献 (WAM 先驱与基础工作)

以下论文是 WAM 范式的重要先驱和基础，在 p7 引用图中被多篇 2026 论文引用：

2023 5x cited

GR-1: 大规模视频生成预训练机器人

ByteDance | Wu et al.

WAM 范式的直接先驱。用大规模视频生成预训练 Transformer，再微调为机器人策略。首次证明"视频预训练→机器人策略"的技术路线可行。直接启发了 DreamZero、GR-2、UVAM 等后续工作。

GR-1 回答了关键问题: 视频生成模型的知识能否迁移到机器人? — 答案是 yes，且泛化能力显著优于纯机器人数据训练。
2024 4x cited

GR-2: 网络规模视频→语言动作模型

ByteDance | Cheang et al.

GR-1 的扩展版。利用网络规模视频数据 (非机器人数据) 预训练，将视频生成能力和语言理解结合。证明互联网视频的 scaling 对 WAM 有效，是 WAM 走向大规模预训练的关键证据。

从 GR-1 到 GR-2: 数据规模从机器人视频扩展到互联网视频，模型能力显著提升——WAM 的 scaling law。
2025 5x cited

UVAM: 统一视频动作模型

ByteDance | Luo et al.

ByteDance GR 系列第三代。统一视频生成和动作预测为单一模型，不再需要分离的视频模型和动作解码器。在多个操作基准上取得 SOTA，被 5 篇 2026 论文引用。

从分离式 (GR-1: 视频→策略) 到统一式 (UVAM: 视频=策略)——统一建模消除了中间环节的信息损失。
2025 3x cited

UWM: 统一世界模型 — 视频+动作扩散耦合

UC Berkeley | Li et al.

将视频预测和动作生成统一到同一个扩散过程中。视频和动作共享去噪 Transformer，使两者相互约束——视频预测提供物理约束，动作生成提供因果结构。

UWM 的核心 insight: 视频和动作不应独立去噪——它们是同一物理过程的两面，联合去噪产生更强的物理一致性。
2024 3x cited

LAPA: 视频潜在动作预训练

UC Berkeley | Ye et al.

从无动作标签的视频中学习潜在动作表示，用于预训练世界模型。与 LAWM 思路相近但方法不同：LAPA 用逆动力学模型推断帧间潜在动作，然后用这些潜在动作预训练策略。

LAPA 和 LAWM 形成"潜在动作预训练"双子星——证明互联网视频即使没有动作标签也包含丰富的动力学信息。
2025 3x cited

DreamGen: 梦境生成解锁机器人泛化

Stanford | Huang et al.

让机器人在"梦中"生成虚拟训练数据。利用视频生成模型合成多样化的交互场景，扩充训练数据。在少样本场景下将泛化能力提升显著。直接启发了 PlayWorld 等自主数据生成工作。

数据瓶颈的新解法: 不是收集更多真实数据，而是让世界模型"做梦"生成数据——类似人类在睡眠中巩固学习。
2025 3x cited

FLARE: 隐式世界建模

MIT | Yu et al.

不显式生成视频或潜在状态预测，而是将世界建模能力隐式编码到策略网络中。通过辅助预测任务（未来观测嵌入）增强策略的物理理解，但推理时不需要额外的预测步骤。

世界建模不一定需要显式预测——隐式方法(FLARE)在训练时注入物理先验，推理时零额外开销，是 WAM 和 VLA 之间的中间路线。

WAM 为什么鲁棒?

WAM 的鲁棒性来自时空先验，且不同架构路线有不同的鲁棒性来源：

  • 像素空间：视频预训练学到了"物体在力的作用下如何运动"的物理直觉
  • 潜在空间：丢弃视觉噪声 (光照/纹理)，保留动力学本质 → 天然对视觉扰动鲁棒
  • 3D 结构化：遮挡不影响 3D 场景理解 → 几何层面的鲁棒性
  • 共性：联合建模状态演化和动作，使决策受物理约束而非表面统计关联

World Model Threat Landscape

世界模型的预测能力带来独特安全风险。提出五级攻击者能力分类和统一威胁模型，扩展 MITRE ATLAS 和 OWASP LLM Top 10 到世界模型场景。
