什么是 WAM?

World Action Model (WAM) 是 2025 年涌现的新范式。核心思想：先学会预测世界如何变化，再从预测中解码出动作。与 VLA 直接从视觉语言到动作的映射不同，WAM 引入了"想象未来"的中间过程。

VLA 路径 (直接映射) ┌──────────┐ ┌──────────┐ │ 观测+语言 │ ──► │ Action │ └──────────┘ └──────────┘ WAM 路径 (世界模型中介) ┌──────────┐ ┌──────────────┐ ┌──────────┐ │ 观测+语言 │ ──► │ 预测未来状态 │ ──► │ Action │ └──────────┘ │ (视频/latent) │ └──────────┘ └──────────────┘ │ 物理动力学先验 (来自视频预训练)

WAM 为什么鲁棒?

WAM 的鲁棒性来自时空先验，且不同架构路线有不同的鲁棒性来源：

  • 像素空间：视频预训练学到了"物体在力的作用下如何运动"的物理直觉
  • 潜在空间：丢弃视觉噪声 (光照/纹理)，保留动力学本质 → 天然对视觉扰动鲁棒
  • 3D 结构化：遮挡不影响 3D 场景理解 → 几何层面的鲁棒性
  • 共性：联合建模状态演化和动作，使决策受物理约束而非表面统计关联
